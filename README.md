A high-performance arcade space shooter inspired by the classic Asteroids. 
This project focuses on clean Java implementation, efficient collision detection, and smooth 2D physics.

A/D for rotate the ship. SPACE for shoting

USAGE:

compile using Java17+ and maven (just mvn clean package in directory with pom.xml) and then put ip address and port on wich game will start.
Then more players can join using the same settings.
